# ADR NNNN: Short decision title

## Status

Proposed, DD Month YYYY.

Supersedes: none. Superseded by: none.

## Context

Describe the problem, forces, constraints, and evidence. State why the decision
is durable enough to record and which compatibility or ownership boundaries it
affects.

## Decision

State the decision in active, testable language. Define ownership, invariants,
failure behavior, versioning, and migration where they matter.

## Consequences

Describe benefits, costs, operational effects, security implications, migration
work, limitations, and follow-up decisions.

## Alternatives considered

Describe viable alternatives and why they were not selected. Include the
conditions that would justify reconsidering this decision.
